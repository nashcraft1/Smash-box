Politique de confidentialité

Smash Box ne collecte rien.

Aucun compte à créer, aucune analyse d'usage, aucune publicité, aucun suivi. L'application n'envoie aucune requête réseau vers nous, car il n'y a de notre côté aucun serveur à qui parler.

Ce que l'application enregistre

Votre record, vos trophées, le thème choisi et votre réglage de vibrations sont enregistrés sur votre appareil. C'est la liste complète.

iCloud

Si vous êtes connecté à iCloud, votre record et vos trophées sont copiés dans le stockage clé-valeur iCloud d'Apple afin de vous suivre entre vos propres appareils. Ces données se trouvent dans votre compte iCloud, sous votre identifiant Apple. Nous ne pouvons pas les voir et n'avons aucun moyen d'y accéder. Désactiver iCloud pour Smash Box dans les Réglages iOS met fin à cela ; le jeu continue exactement pareil, sur ce seul appareil.

Enfants

Smash Box ne collecte de données sur personne, quel que soit son âge.

Supprimer vos données

Supprimer l'application efface tout ce qu'elle avait enregistré sur cet appareil. Pour supprimer aussi la copie synchronisée, désactivez iCloud pour Smash Box dans les Réglages avant de la supprimer.

Modifications

Si cette politique change, la nouvelle version paraîtra sur cette page avec une nouvelle date.
